Una cuenta regresiva estilo subathon en tu stream, a la que los espectadores suman tiempo.

<Screenshot
  name="timer-preview"
  alt="La vista previa del temporizador en Herramientas → Temporizador: el título Subathon sobre un reloj en 01:04:57"
/>

<Steps>

1. En **Herramientas**, abre **Temporizador** y define el **Tiempo inicial**, 60 minutos por defecto.
2. En **Tiempo sumado**, define lo que suma cada evento.
3. Agrega el overlay del temporizador a tu app de streaming (mira [cómo agregar un overlay](/es/docs/guides/adding-an-overlay/)):

   ```
   http://tokio-app.local:37891/timer/
   ```

4. Presiona **Iniciar**.

</Steps>

## Controles

<Screenshot
  name="timer-controls"
  alt="El temporizador en marcha, con sus controles, el tiempo inicial y la URL del overlay"
/>

| Botón                   | Qué hace                                                                                                                                                                                |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Iniciar**             | Pone en marcha el reloj desde el **Tiempo inicial**, o lo reanuda.                                                                                                                      |
| **Pausar**              | Congela el reloj, pero los eventos siguen sumando tiempo. El estado dice **En pausa, sigue sumando tiempo**.                                                                            |
| **Detener**             | Congela el reloj, y los eventos no suman nada hasta que vuelvas a **Iniciar**. El estado dice **Detenido, no suma tiempo**.                                                             |
| **Restablecer**         | Pregunta **¿Restablecer el temporizador?** y vuelve al tiempo inicial. Se pierde el tiempo sumado hasta ahora.                                                                          |
| **Agregar**, **Quitar** | Cambian el reloj en los minutos que escribas, como una donación que llegó por otro lado. Aparecen después de **Iniciar**, no usan el **Multiplicador** y paran en el **Tiempo máximo**. |

Al llegar a 0 el estado dice **Se acabó el tiempo**, e **Iniciar** espera a que uses **Agregar** o **Restablecer**. El reloj sigue corriendo aunque salgas de su página, y se pausa cuando el LIVE termina o Tokio se desconecta, salvo que desmarques **Pausar cuando el LIVE termine o se desconecte**.

## Tiempo sumado

<Screenshot
  name="timer-time-added"
  alt="Tiempo sumado: el multiplicador, el tiempo máximo y los segundos que suma cada evento"
/>

Los eventos suman tiempo solo después de que presionas **Iniciar**. Por defecto:

| Evento                      | Suma                                             | De                                |
| --------------------------- | ------------------------------------------------ | --------------------------------- |
| **Monedas**                 | 1 segundo por moneda                             | TikTok                            |
| **Me gusta**                | 10 segundos cada 100 Me gusta                    | TikTok                            |
| **Seguidores nuevos**       | 30 segundos cada uno                             | TikTok, Twitch                    |
| **Compartidos**             | 10 segundos cada uno                             | TikTok                            |
| **Super Fans nuevos**       | 300 segundos cada uno                            | TikTok                            |
| **Mensajes del chat**       | 0, una vez por espectador cada 30 segundos       | Todas                             |
| **Suscripciones nuevas**    | 300 segundos cada una, también las renovaciones  | Twitch, Kick, miembros de YouTube |
| **Suscripciones regaladas** | 300 segundos por suscripción regalada            | Twitch, Kick, miembros de YouTube |
| **Bits**                    | 1 segundo por Bit                                | Twitch                            |
| **Kicks**                   | 1 segundo por Kick                               | Kick                              |
| **Super Chats**             | 300 segundos cada uno, sin importar cuánto costó | YouTube                           |

Solo aparecen las filas de las [plataformas](/es/docs/connect/#varias-plataformas-juntas) de tu perfil.

- Con 0 segundos, el evento no suma tiempo. **Multiplicador** multiplica todos los eventos: 2 es tiempo doble.
- **Tiempo máximo** deja de sumar tiempo cuando el reloj llega a ese valor. Con 0 no hay límite.
- Los mensajes del chat cuentan solo si tienen la palabra clave que escribas después de **solo mensajes con**, buscada igual que en una [alerta de chat](/es/docs/features/alerts/#alertas-de-chat-emotes-y-entradas). Déjala vacía para contar cualquier mensaje.

## En el stream

El overlay muestra el reloj, un **Título** opcional y lo que suma cada tanda de eventos, como **+1:30**. El resto se configura en **Aspecto**.

<Screenshot
  name="timer-look"
  alt="Aspecto: los colores, el título, el aviso, las fuentes y los nombres que se muestran para cada activador"
/>

- **Aviso** pone el reloj en su color de aviso esa cantidad de minutos antes del final. Con 0 se desactiva.
- **Fuente del reloj** y **Fuente del título** muestran las fuentes de tu computadora. Si tu app de streaming está en otra computadora, mira [Fuentes y sonido](/es/docs/guides/adding-an-overlay/#fuentes-y-sonido).
- **Mostrar el multiplicador** lo muestra, como **×2**, mientras no sea 1.
- **Mostrar los activadores, uno a la vez** muestra lo que suma cada evento, como **Seguir +30s**, con los nombres que escribas.

## Perfiles y reinicios

Cada perfil tiene su propio temporizador, y cambiar de perfil lo pausa. Si Tokio se cierra mientras corre, vuelve en pausa con más o menos el tiempo que tenía.
