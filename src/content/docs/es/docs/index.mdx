Tokio es una app de escritorio para Windows, macOS y Linux que reacciona a tu TikTok LIVE. Lee el chat en voz alta, recibe pedidos de canciones, reproduce alertas, ejecuta comandos en Minecraft y controla tus overlays.

¿Eres nuevo? [Instala Tokio](/es/docs/install/) y luego [conéctalo a tu LIVE](/es/docs/connect/).

## Lo que necesitas

- Una computadora con Windows 10 o posterior, macOS 13 o posterior, o Linux, abierta mientras transmites.
- Una clave de API gratuita de [Euler Stream](https://www.eulerstream.com/register), para conectarte a tu LIVE.
- Para los overlays, OBS Studio, TikTok LIVE Studio u otra app con fuente de navegador.
- Para la música, Spotify Premium, o YouTube. Con YouTube Premium te saltas los anuncios.
- Para los juegos, Minecraft Bedrock Edition, o Java Edition con Fabric y el [mod de Tokio](/es/docs/features/games/#java-edition).

## Funciones

- **[Overlays](/es/docs/features/overlays/)**: instala overlays oficiales o importa los tuyos.
- **[Texto a voz](/es/docs/features/text-to-speech/)**: lee el chat en voz alta.
- **[Alertas](/es/docs/features/alerts/)**: sonidos, voces, imágenes y videos para regalos, seguidores y más.
- **[Música](/es/docs/features/music-requests/)**: los espectadores ponen canciones en cola en YouTube o Spotify.
- **[Juegos](/es/docs/features/games/)**: los regalos y el chat hacen aparecer criaturas y ejecutan comandos en Minecraft.
- **[Comandos de chat](/es/docs/features/chat-commands/)**: lo que pueden escribir los espectadores, como `!play`.
- **[Temporizador](/es/docs/features/countdown-timer/)**: un reloj al que los espectadores le suman tiempo.
- **[Overlay Studio](/es/docs/features/overlay-studio/)**: tu propio overlay, hecho con texto, imágenes, videos y cámaras.
- **[Monedas](/es/docs/features/coin-stats/)**: las monedas y los regalos de cada LIVE y quienes los enviaron.
- **[Fans](/es/docs/features/fans/)**: los espectadores con nivel de fan, primero los de nivel más alto.
