Tokio serves its overlays as web pages, and your streaming app shows them over your stream.

<Steps>

1. **Turn on the overlay server**

   In **Settings → Overlay Server**, turn on **Enable Server** and confirm. The first time, accept the administrator prompt (your password on macOS and Linux) so Tokio can add its address to your hosts file.

   <Screenshot
     name="settings-overlay-server"
     alt="Settings → Overlay Server, with the server on and the computer's network address"
   />

2. **Copy the overlay's address in Tokio**

   Each address starts with `http://tokio-app.local:37891`, like `http://tokio-app.local:37891/timer/`.

   | Copy it from                                                                          | Address               |
   | ------------------------------------------------------------------------------------- | --------------------- |
   | An [overlay's](/docs/features/overlays/) card on **Overlays**                         | `/<overlay-id>/`      |
   | An [alert's](/docs/features/alerts/#images-and-videos) **Media** tab                  | `/alerts/<alert-id>/` |
   | **Tools**, for the [timer](/docs/features/countdown-timer/)                           | `/timer/`             |
   | **Games**, for the [games overlay](/docs/features/games/#show-your-actions-on-stream) | `/games/minecraft/`   |
   | **Games**, for its column 2                                                           | `/games/minecraft/2/` |

3. **Add it in your streaming app**

   Paste the address in a new browser source:

</Steps>

<Tabs>
  <TabItem label="OBS Studio">

1. In **Sources**, click **+** and choose **Browser**.
2. Paste the address and set the width and height to your canvas size.

  </TabItem>
  <TabItem label="TikTok LIVE Studio">

1. Click **Add source** and choose **Link**.
2. Paste the address and place the overlay on your scene.

  </TabItem>
  <TabItem label="Other apps">

1. Add a browser or web source.
2. Paste the address.

  </TabItem>
</Tabs>

Overlays use `tokio-app.local` because TikTok LIVE Studio doesn't accept `localhost` links.

## On another computer

If your streaming app runs on another computer on your network, point `tokio-app.local` there to the computer with Tokio.

<Flow
  label="A streaming app on another computer"
  stops={[
    {
      title: "Computer with Tokio",
      code: "192.168.1.20",
      text: "Its address is in <strong>Settings → Overlay Server</strong>",
    },
    {
      title: "Computer with your streaming app",
      code: "192.168.1.20 tokio-app.local",
      text: "A line in its hosts file",
    },
  ]}
/>

Add that line to the other computer's hosts file, as administrator: `C:\Windows\System32\drivers\etc\hosts` on Windows, `/etc/hosts` on macOS and Linux. Or add a DNS entry for `tokio-app.local` on your router.

If Windows asks whether to allow Tokio through the firewall, allow it, or the other computer can't connect.
