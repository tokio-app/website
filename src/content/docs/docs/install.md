---
title: Install
description: Download and install Tokio on Windows, macOS or Linux.
---

Tokio runs on Windows, macOS and Linux. Download the installer for your system from the [download page](/download/) or the [latest release](https://github.com/tokio-app/tokio/releases/latest) and run it. It downloads and installs the latest version of Tokio.

| System                | Installer                          |
| --------------------- | ---------------------------------- |
| Windows (x64)         | `Tokio-Installer-windows-x64.exe`  |
| macOS (Apple Silicon) | `Tokio-Installer-mac-arm64.zip`    |
| macOS (Intel)         | `Tokio-Installer-mac-x64.zip`      |
| Linux (x64)           | `Tokio-Installer-linux-x64.tar.gz` |

Each release also has the app's own packages: the Windows setup, the macOS zips and the Linux AppImage. Use them if you'd rather skip the installer.

All features work on every system, except the voices installed on the system: they're only available on Windows. TikTok and Edge voices work everywhere.

:::caution[macOS]
Tokio and its installer aren't notarized yet, so macOS may block them the first time. Open it from Finder with right-click → **Open**, or allow it in **System Settings → Privacy & Security**.
:::

:::note[Linux]
The AppImage needs FUSE to run.
:::

## Updates

Tokio checks for new versions on its own, from the latest published release on GitHub. You don't need to run the installer again.
