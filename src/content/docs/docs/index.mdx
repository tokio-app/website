Tokio is a desktop app for Windows, macOS and Linux that reacts to your TikTok LIVE. It reads chat aloud, takes song requests, plays alerts, runs commands in Minecraft and drives your overlays.

## Features

- **[Text-to-speech](/docs/features/text-to-speech/)**: chat read aloud.
- **[Music requests](/docs/features/music-requests/)**: viewers queue songs on YouTube Music or Spotify.
- **[Alerts](/docs/features/alerts/)**: sounds, voices, images and videos for gifts, follows and more.
- **[Games](/docs/features/games/)**: gifts and chat spawn mobs and run commands in Minecraft.
- **[Overlays](/docs/features/overlays/)**: install official overlays or import your own.
- **[Countdown timer](/docs/features/countdown-timer/)**: a clock viewers add time to.
- **[Profiles and settings](/docs/features/profiles-and-settings/)**: separate setups for different streams.
