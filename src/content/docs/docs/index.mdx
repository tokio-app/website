Tokio is a desktop app for Windows, macOS and Linux that connects to your TikTok LIVE and reacts to what happens in it. It reads chat aloud, takes song requests, plays sounds when someone follows or sends a gift, and drives overlays you add to **OBS**, **TikTok LIVE Studio** or any streaming app that can show a web page.

Tokio runs on your own computer. Keep it open while you stream.

## Features

- **[Text-to-speech](/docs/features/text-to-speech/)**: chat messages are read aloud as they come in.
- **[Music requests](/docs/features/music-requests/)**: viewers request songs from chat, played from YouTube or Spotify.
- **[Alerts](/docs/features/alerts/)**: play a sound for any LIVE event.
- **[Overlays](/docs/features/overlays/)**: import overlays and set them up from the gallery.
- **[Profiles and settings](/docs/features/profiles-and-settings/)**: keep separate settings for different streams.

## Dashboard

Enter your TikTok username on the **Home** page to connect to your LIVE. Turn each feature on or off for the session and watch the live stats as viewers join, like and send gifts.
