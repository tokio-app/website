Tokio runs on Windows 10 or later, macOS 13 or later, and Linux. Get it here or from the [latest release](https://github.com/tokio-app/tokio/releases/latest).

<DownloadTable />

<Tabs>
  <TabItem label="Windows">

<Steps>

1. Run the setup. It installs Tokio for your user and opens it.
2. Tokio isn't signed yet. If you see **Windows protected your PC**, choose **More info**, then **Run anyway**.

</Steps>

  </TabItem>
  <TabItem label="macOS">

<Steps>

1. Unzip the download and move **Tokio** to your Applications folder.
2. Tokio isn't notarized yet, so macOS blocks it the first time. Open it once, then in **System Settings → Privacy & Security**, click **Open Anyway** and confirm.

</Steps>

  </TabItem>
  <TabItem label="Linux">

<Steps>

1. Make the AppImage executable with `chmod +x`, or in the file's properties.
2. Run it. It needs FUSE.

</Steps>

  </TabItem>
</Tabs>

Everything works on every system, except the system voices, which only Windows has.

The first time Tokio opens, a short tour shows you around. **Take the tour** in **About** shows it again.

<details>
<summary>Uninstall</summary>

On Windows, uninstall Tokio from **Settings → Apps**. On macOS, move Tokio from Applications to the Trash, and on Linux, delete the AppImage.

Your settings and files stay in the `.tokio` folder. Delete it too to remove everything, see [Your files](/docs/features/profiles-and-settings/#your-files).

</details>

## Updates

Tokio checks for new versions when it starts and every few hours. On Windows and Linux it downloads them, and installs them when you quit Tokio. While one downloads, a ring fills in the title bar, and **About** shows its progress.

To update right away, click **Restart to update** in the title bar. While you're connected it's gray and asks first, since Tokio disconnects from the LIVE to restart.

On macOS, **Download update** opens the release page. Turn the checks off in **Settings → Updates**, or check any time from **About**.

After an update, **What's new** shows the new version's main changes, when it has notes, with a link to its full release notes on GitHub.
