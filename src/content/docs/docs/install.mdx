Tokio runs on Windows, macOS 13 or later, and Linux. Get it here or from the [latest release](https://github.com/tokio-app/tokio/releases/latest).

<DownloadTable />

<Tabs>
  <TabItem label="Windows">

<Steps>

1. Run the setup. It installs Tokio for your user and opens it.
2. Tokio isn't signed yet. If you see **Windows protected your PC**, choose **More info**, then **Run anyway**.

</Steps>

  </TabItem>
  <TabItem label="macOS">

<Steps>

1. Unzip the download and move **Tokio** to your Applications folder.
2. Tokio isn't notarized yet. If macOS blocks it, right-click it in Finder and choose **Open**, or allow it in **System Settings → Privacy & Security**.

</Steps>

  </TabItem>
  <TabItem label="Linux">

<Steps>

1. Make the AppImage executable with `chmod +x`, or in the file's properties.
2. Run it. It needs FUSE.

</Steps>

  </TabItem>
</Tabs>

Everything works on every system, except the system voices, which only Windows has.

## Your Euler Stream key

Tokio connects through [Euler Stream](https://www.eulerstream.com) with your own API key: [sign up](https://www.eulerstream.com/register) for free and paste it in **Settings → TikTok LIVE**. Your [plan](https://www.eulerstream.com/pricing) sets how often you can connect.

<Screenshot
  name="settings-tiktok-live"
  alt="The Euler Stream API key field in Settings → TikTok LIVE"
/>

## Updates

Tokio checks for new versions when it starts and every few hours. On Windows and Linux it downloads them for you: click **Restart to update** in the title bar. On macOS, **Download update** opens the release page.

<Screenshot
  name="update-button"
  alt="The title bar with the profile menu and the Restart to update button"
/>

Turn the checks off in **Settings → Updates**, or check any time from **About**.
