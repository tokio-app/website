Tokio runs on Windows, macOS 13 or later, and Linux. Get it from the [download page](/download/) or the [latest release](https://github.com/tokio-app/tokio/releases/latest).

On Windows, run the setup: it installs Tokio for your user and opens it. On macOS and Linux you download Tokio itself.

<DownloadTable />

All features work on every system, except the voices installed on the system: they're only available on Windows. TikTok and Edge voices work everywhere.

:::caution[Windows]
Tokio isn't signed yet, so Windows may show **Windows protected your PC** when you run the setup. Choose **More info**, then **Run anyway**.
:::

:::caution[macOS]
Unzip the download and move **Tokio** to your Applications folder. Tokio isn't notarized yet, so macOS may block it the first time. Open it from Finder with right-click → **Open**, or allow it in **System Settings → Privacy & Security**.
:::

:::note[Linux]
Make the AppImage executable with `chmod +x` (or in the file's properties) and run it. It needs FUSE.
:::

## Your Euler Stream key

Tokio connects to TikTok LIVE through [Euler Stream](https://www.eulerstream.com), which signs each connection with your own API key. Before your first LIVE, [sign up](https://www.eulerstream.com/register) for free and paste your key in **Settings → TikTok LIVE**. You only do this once. Your [Euler Stream plan](https://www.eulerstream.com/pricing) sets how often you can connect.

## Updates

Tokio checks for new versions on its own, from the latest published release on GitHub. On Windows and Linux it downloads them in the background and installs them when you restart. On macOS it opens the release page, where you download the new zip.
