Tokio runs on Windows, macOS 13 or later, and Linux. Get it from the [download page](/download/) or the [latest release](https://github.com/tokio-app/tokio/releases/latest). On Windows, the setup installs Tokio for your user and opens it. On macOS and Linux you download Tokio itself.

<DownloadTable />

Everything works on every system, except the voices installed on the system, which only Windows has.

:::caution[Windows]
Tokio isn't signed yet, so Windows may show **Windows protected your PC**. Choose **More info**, then **Run anyway**.
:::

:::caution[macOS]
Unzip the download and move **Tokio** to your Applications folder. Tokio isn't notarized yet, so macOS may block it the first time: open it from Finder with right-click → **Open**, or allow it in **System Settings → Privacy & Security**.
:::

:::note[Linux]
Make the AppImage executable with `chmod +x` (or in the file's properties) and run it. It needs FUSE.
:::

## Your Euler Stream key

Tokio connects to TikTok LIVE through [Euler Stream](https://www.eulerstream.com), which signs each connection with your own API key. [Sign up](https://www.eulerstream.com/register) for free and paste your key in **Settings → TikTok LIVE**. Your [plan](https://www.eulerstream.com/pricing) sets how often you can connect.

![The Euler Stream API key field in Settings → TikTok LIVE](../../../assets/screenshots/settings-tiktok-live.png)

## Updates

Tokio checks GitHub for new versions when it starts and every few hours.

- On Windows and Linux it downloads them in the background. Click **Restart to update** in the title bar to install one.
- On macOS, **Download update** in the title bar opens the release page, where you download the new zip.

Turn the checks off in **Settings → Updates**, or check any time from **About**.
