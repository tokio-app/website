Profiles keep each stream's setup apart, and **Settings** holds what they all share. Tokio saves your changes as you make them.

## Profiles

Each profile has its own TTS, music, alerts, game actions, countdown, [LIVE history](/docs/features/coin-stats/), [fans](/docs/features/fans/), and the [platforms](/docs/connect/#several-platforms-together) and channels it connects to. Switch profiles from the title bar while you're not connected.

<Screenshot
  name="profiles-menu"
  alt="The profile menu in the title bar, with two profiles"
/>

All profiles share the installed overlays, Overlay Studio's overlays, the [Library](/docs/features/alerts/#library), the test overlays, Home's **Active features** and **Activity feed**, and the Minecraft connection.

In **Settings → Profiles**, **New** creates a blank profile, **Clone** copies one without its LIVE history or fans, and **Rename** changes the active one's name. Names need 3 or more characters and must be unique. Point at a button to see its name.

<Screenshot
  name="settings-profiles"
  alt="Settings → Profiles, with the active profile and the New, Clone, Rename, Delete profile, Import and Export buttons"
/>

**Delete profile** asks which profile to delete, then deletes it with its LIVE history and fans. The active profile can't be deleted, so switch first, and the button is grayed out when you have only one.

**Export** saves the active profile's settings as a file, and **Import** adds one as a new profile. The file holds no sounds, images, videos, game pictures, LIVE history or fans, so on another computer, pick its alerts' sounds again.

## Settings

**TikTok LIVE** and **Chat translation** show only on a profile with TikTok, and **Twitch** on one with Twitch.

| Section              | What it's for                                                                                                                                                                                   |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TikTok LIVE**      | Your [Euler Stream](https://www.eulerstream.com) API key, which Tokio needs to connect. [Sign up](https://www.eulerstream.com/register) for free.                                               |
| **Twitch**           | [Sign in to Twitch](/docs/connect/#sign-in-to-twitch), once for every profile.                                                                                                                  |
| **Profiles**         | [Your profiles](#profiles): make, rename, delete, import and export them.                                                                                                                       |
| **Voice engines**    | Your TikTok session ID and your keys for [other voices](/docs/features/text-to-speech/#voices). Removing a key puts the default voice back where that service's voices were picked.             |
| **Overlay server**   | The server for overlays, and your network address for a streaming app on [another computer](/docs/guides/adding-an-overlay/#on-another-computer).                                               |
| **Remote control**   | The [live controls](/docs/features/live-controls/#from-your-phone-or-another-computer) on your phone, and the key for the [Control API](/docs/developers/control-api/). Off until you check it. |
| **AI assistants**    | The setup to [connect an AI assistant](/docs/developers/mcp/). It uses **Remote control**'s switch and key.                                                                                     |
| **Shortcuts**        | Keys for the [live controls](/docs/features/live-controls/#shortcuts), in any app.                                                                                                              |
| **Chat translation** | Translates chat into your language. See [Chat translation](/docs/features/chat-translation/).                                                                                                   |
| **Language**         | English or Spanish for Tokio and the text it writes on overlays. **System language** follows your computer's. Voices don't change.                                                              |
| **Updates**          | Checks for new versions of Tokio on startup and every 6 hours, and updates [official overlays](/docs/features/overlays/#install-an-official-overlay). Uncheck either one to turn it off.        |
| **Tray**             | Keeps Tokio in the tray (the menu bar on macOS) when you close it. Click its icon to bring it back.                                                                                             |
| **Logs**             | **Export logs** for a [bug report](#your-files). **Detailed logs** also writes every LIVE event to them: turn it off once you've sent them.                                                     |

## Notifications

When something fails, such as a voice that can't be made or a missing sound, Tokio tells you what went wrong. The bell in the title bar keeps the session's last 50.

## Your files

Tokio keeps your settings and files in the `.tokio` folder in your user folder: `C:\Users\<you>\.tokio` on Windows, `~/.tokio` on macOS and Linux.

| Folder            | What's in it                                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- |
| `settings`        | Settings, and what every profile shares                                                   |
| `profiles`        | Each profile's settings                                                                   |
| `sounds`, `media` | The Library's sounds, images and videos                                                   |
| `overlays`        | The overlays you installed or imported                                                    |
| `games/minecraft` | The Minecraft pictures                                                                    |
| `fans`            | Each profile's fans                                                                       |
| `history`         | Each profile's past LIVEs, for LIVE history                                               |
| `extra`           | TikTok's gift list, the gifts viewers sent that aren't on it, and Block ads' filter lists |
| `logs`            | What Tokio did, for bug reports                                                           |

Your YouTube and Spotify sign-ins are in Tokio's app data folder instead: `%APPDATA%\tokio` on Windows, `~/Library/Application Support/tokio` on macOS and `~/.config/tokio` on Linux.

To report a bug, open an [issue on GitHub](https://github.com/tokio-app/tokio/issues) and attach the .zip that **Export logs** saves in **Settings → Logs**. The logs include the channels you connect to, and with **Detailed logs** on, your viewers' usernames too.
