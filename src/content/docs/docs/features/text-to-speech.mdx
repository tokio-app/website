## Voices

| Engine      | Notes                                                                                                                                                                                                                   |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TikTok**  | TikTok's voices. They go through `tiktok-tts.weilnet.workers.dev`, a proxy run by a third party, which gets the text of every message they read. Add your TikTok session ID in **Settings → Voice Engines** to skip it. |
| **Edge**    | Microsoft Edge's voices.                                                                                                                                                                                                |
| **Windows** | The voices installed on Windows, SAPI and OneCore, 32-bit ones included.                                                                                                                                                |

Search the list, filter it by engine and language, and play any voice before you pick it.

## Format

Read every message, or only the ones that start with a dot, a slash or a command of your own. Choosing **Custom Command** fills in `!tts`, which you can change. The command isn't read aloud, and with the command left blank nothing is read.

<Screenshot
  name="tts-format"
  alt="The Format section: which messages get read, the message template and Remove Emojis"
/>

The **Message Template** sets what's read:

| Placeholder  | Replaced with                        |
| ------------ | ------------------------------------ |
| `{username}` | The viewer's display name            |
| `{handle}`   | The viewer's handle, without the `@` |
| `{comment}`  | The chat message                     |

`{username} {comment}` reads "Lucia hi from Lima!". **Remove Emojis** leaves emojis out, and skips messages that are only emojis.

A message with nothing to read is skipped: when the filled template has no letter, number or emoji, like `{comment}` with "?" alone.

## Replacements

Teach the voice to say acronyms, slang and names. Each one swaps a whole word, in any case, and applies before **Remove Emojis**, so ❤️ can become "love".

<Screenshot
  name="tts-replacements"
  alt="Two replacements: brb is read as be right back, and gg as good game"
/>

## Permissions

Uncheck **Allow Everyone** to allow only followers, superfans, moderators or a minimum fan level. With **Enable Whitelist / Blacklist**, blacklisted @handles are never read, and a whitelist with names lets only them talk.

<Screenshot
  name="tts-permissions"
  alt="The Permissions section with the whitelist and blacklist on and one handle blacklisted"
/>

## Protection

A **Cooldown** and a **Max Queue Length** keep chat from flooding the voice. Messages over the **Max Comment Length**, or with a banned word in the comment, name or @handle, are skipped, even with look-alike letters or hidden characters.

<Screenshot
  name="tts-protection"
  alt="The Protection section: cooldown, maximum queue length, maximum comment length and banned words"
/>

Replacements, **Remove Emojis** and banned words also apply to [alerts that speak](/docs/features/alerts/#spoken-messages). [Music requests](/docs/features/music-requests/#who-can-request) have their own permissions.
