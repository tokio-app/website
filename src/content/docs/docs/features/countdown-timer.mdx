A subathon-style countdown on your stream, which viewers add time to.

<Screenshot
  name="timer-preview"
  alt="The timer's preview in Tools → Countdown: the title Subathon over a clock at 01:04:57"
/>

<Steps>

1. In **Tools**, open **Countdown** and set the **Starting time**, 60 minutes by default.
2. Under **Time added**, set what each event adds.
3. Add the timer's overlay to your streaming app (see [Adding an overlay](/docs/guides/adding-an-overlay/)):

   ```
   http://tokio-app.local:37891/timer/
   ```

4. Press **Start**.

</Steps>

## Controls

<Screenshot
  name="timer-controls"
  alt="The countdown running, with its controls, the starting time and the overlay URL"
/>

| Button              | What it does                                                                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Start**           | Runs the clock from the **Starting time**, or carries on.                                                                                                         |
| **Pause**           | Holds the clock while events still add time. The status reads **Paused, still adding time**.                                                                      |
| **Stop**            | Holds the clock, and events add nothing until you **Start** again. The status reads **Stopped, adding no time**.                                                  |
| **Reset**           | Asks **Reset the countdown?**, then puts the starting time back. The time added so far is lost.                                                                   |
| **Add**, **Remove** | Change the clock by the minutes you enter, say for a donation from elsewhere. They work once you **Start**, skip the **Multiplier** and stop at **Maximum time**. |

At 0 the status reads **Time's up**, and **Start** waits until you use **Add** or **Reset**. The clock keeps running when you leave its page, and pauses when the LIVE ends or Tokio disconnects, unless you uncheck **Pause when the LIVE ends or disconnects**.

## Time added

<Screenshot
  name="timer-time-added"
  alt="Time added: the multiplier, the maximum time and the seconds each event adds"
/>

Events add time only after you press **Start**. By default:

| Event              | Adds                                | From                          |
| ------------------ | ----------------------------------- | ----------------------------- |
| **Coins**          | 1 second per coin                   | TikTok                        |
| **Likes**          | 10 seconds every 100 likes          | TikTok                        |
| **Follows**        | 30 seconds each                     | TikTok, Twitch                |
| **Shares**         | 10 seconds each                     | TikTok                        |
| **New Super Fans** | 300 seconds each                    | TikTok                        |
| **Chat messages**  | 0, once per viewer every 30 seconds | All                           |
| **New subs**       | 300 seconds each, renewals too      | Twitch, Kick, YouTube members |
| **Gifted subs**    | 300 seconds per gifted sub          | Twitch, Kick, YouTube members |
| **Bits**           | 1 second per Bit                    | Twitch                        |
| **Kicks**          | 1 second per Kick                   | Kick                          |
| **Super Chats**    | 300 seconds each, whatever it cost  | YouTube                       |

You see only the rows for your profile's [platforms](/docs/connect/#several-platforms-together).

- 0 seconds leaves an event out. **Multiplier** multiplies every event: 2 is double time.
- **Maximum time** stops adding time once the clock reaches it. 0 is no limit.
- Chat messages count only with the keyword you type after **only messages with**, matched like a [chat alert's](/docs/features/alerts/#chat-emote-and-join-alerts). Leave it empty to count any message.

## On stream

The overlay shows the clock, an optional **Title**, and what each burst adds, like **+1:30**. Set the rest in **Look**.

<Screenshot
  name="timer-look"
  alt="Look: the colors, the title, the warning, the fonts and the names shown for each trigger"
/>

- **Warning** turns the clock to its warning color that many minutes before the end. 0 turns it off.
- **Clock font** and **Title font** list the fonts on your computer. For a streaming app on another computer, see [Fonts and sound](/docs/guides/adding-an-overlay/#fonts-and-sound).
- **Show the multiplier** shows it, like **×2**, while it isn't 1.
- **Show the triggers, one at a time** shows what each event adds, like **Follow +30s**, with the names you type.

## Profiles and restarts

Each profile has its own timer, and switching profiles pauses it. If Tokio closes while it runs, it comes back paused with about the time it had.
